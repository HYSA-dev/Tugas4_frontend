# Tugas Praktikum 4 - Form Input Interaktif Produk UMKM

Proyek ini adalah implementasi form input interaktif menggunakan JavaScript ES6 untuk katalog produk UMKM.

## Fitur Utama
1. **Form Input Interaktif**: Mendukung input Nama (Text), Kategori (Select Dropdown), Harga (Number), dan Stok (Number).
2. **Live Preview**: Menampilkan draf input secara real-time menggunakan event `input` dan `change`.
3. **Validasi & Feedback Visual**: Menampilkan pesan sukses/gagal di antarmuka tanpa `alert()` bawaan browser.
4. **Mock Data Simulation**: Menyimpan produk baru ke dalam *in-memory array of objects* dan menampilkan hasilnya di Console Browser.
